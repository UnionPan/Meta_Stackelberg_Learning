# E2.2a Trimmed Defense Operators 里程碑报告

## 1. 阶段假设

E2.1 已证明 `clip_radius α` 能形成非平坦响应面。E2.2a 只建立第二个动作维度
`trim_ratio β` 的可信物理执行语义：客户端等权、逐坐标排序、每端删除
`floor(nβ)` 个值，并固定组合顺序为先逐客户端全模型 L2 clipping、再 coordinate trimmed mean。

本阶段不运行四攻击矩阵，不训练 policy，不宣称总 E2 gate 已通过。

## 2. 模块和接口

- `DefenseAction(clip_radius, trim_ratio=0.0)`：二维不可变物理动作；
- `ClippedTrimmedActionCodec`：`[-1,1]^2` 到 `α × β` 的可逆线性映射；
- `CoordinateTrimmedMean(β)`：满足现有 `Aggregator` protocol 的等权 robust aggregation；
- `TrimmingSummary`：client count、per-tail trim count 与 retained count；
- `_clip_client_updates`：E2.1 clipping 的 package-private 纯 helper；
- `ClippedTrimmedMean(α, β)`：唯一 canonical clip→trim 组合路径；
- `DefenseAggregationSummary`：组合阶段的 immutable clipping/trimming 统计。

clean/attack RoundEngine、Episode、federated types 与 aggregation protocol 均未修改。

## 3. 算法与数据流

```text
policy vector [a0, a1]
 -> 2D codec
 -> DefenseAction(α, β)
 -> validate all client update structures/dtypes/finite values
 -> per-client global L2 clip by α
 -> per-coordinate sort
 -> remove floor(nβ) from each tail
 -> equal-client mean of retained values
 -> ModelState aggregate delta
```

`num_examples`、client ID、malicious flag 和 metadata 不参与 trimmed mean。`β=0` 精确等价于
equal-client mean，不在样本数不等时冒充 FedAvg。

## 5. 预期与实际结果

### 5.1 等权与样本权重隔离

两个 scalar updates `0` 与 `2` 的 `num_examples` 分别为 1 与 99：

```text
CoordinateTrimmedMean(β=0) = 1
sample-weighted FedAvg      = 1.98
```

测试确认实现返回 exact float32 `1.0`，因此没有静默继承 FedAvg 权重。

### 5.2 逐坐标手算

五个二维 update：

```text
[0,100], [1,3], [2,2], [3,1], [100,0]
```

`β=0.2` 时每端删除一个值。两个 coordinate 的 retained values 都均值为 2，实际 aggregate
exact 为 `[2,2]`。第二个 update 即使拥有 100 个 examples 也不改变结果。

### 5.3 floor 语义

| n | β | per-tail k | retained |
|---:|---:|---:|---:|
|4|0.24|0|4|
|4|0.25|1|2|
|5|0.20|1|3|
|6|0.40|2|2|

所有 summary 与 aggregate slice 使用同一个 `floor(nβ)` 结果。

### 5.4 composition 非交换反例

输入：

```text
[14,-10], [-16,-8], [-4,13], [-2,-17], [-7,4]
α=5, β=0.2
```

实际 canonical clip→trim：

```text
[-2.1319506, -0.8871881]
```

反向 trim→clip：

```text
[-3.4022555, -3.6639671]
```

二者显著不同，测试不只验证某个输出，还证明组合顺序已被锁定。

## 6. 单元与性质证据

- action：旧的一参数构造继续得到 `trim_ratio=0`；α/β finite 和 range fail fast；
- codec：二维 endpoints、midpoint、round-trip、shape、dtype、finite、range、独立返回数组；
- trimmed mean：scalar/vector/multi-tensor、odd/even、floor、dtype、equal weighting；
- properties：permutation invariance、metadata blindness、input immutability；
- validation：empty、non-finite、shape/dtype mismatch、非法 client count；
- composition：clip bound、β=0 decomposition exact、pure summary、protocol conformance；
- E2.1 的 action、clipping、response surface 回归继续通过。

fresh focused defense operator suite：79 项通过。

## 8. 与历史实现和 E2.1 的差异

- 历史 Meta-SG 将 α/β 解码和 aggregation 混在 environment/runner；canonical 实现将 codec、
  physical action 与 aggregation 分离；
- E2.1 的 `ClippedAggregator(FedAvg)` 保留 sample weighting；E2.2a 的 trimmed family 明确等权；
- 两者共享同一 per-client global L2 clipping helper，不存在第二套 norm 语义；
- `ClipRadiusActionCodec` 保留，便于一维消融；二维 codec 是新增接口而非破坏性替换。

## 9. 已知限制

- 小 client sample size 使连续 β 映射成离散 `k` 台阶；
- coordinate trimming 破坏 update 的跨坐标联合排序；
- operator 正确不代表任何攻击上的 defense effectiveness；
- 尚未验证四攻击 task 的 active-cell ratio 或较优动作区域差异；
- 尚无 follower、defender learning、support/query 或 meta update 证据。
