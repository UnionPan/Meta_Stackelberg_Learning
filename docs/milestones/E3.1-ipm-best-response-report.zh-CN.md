# E3.1 IPM Follower Best Response 里程碑报告

> **2026-07-12 审计更新：** 本报告保留原始 per-commitment strict-improvement Gate 的失败证据。
> 该判据在 initial response 已处于 query-oracle plateau 时会产生假阴性，已由
> `E3.1r-oracle-regret-gate-report.zh-CN.md` 的预声明 oracle-regret Gate 取代。原始结果不删除、不改写。

## 1. 结论

E3.1 的 strict committed-leader、follower-only finite-candidate response、capability-safe support proxy、
fixed oracle 和 frozen independent query execution 已实现。预声明总 Gate **未通过**：强 clipping
commitment `(α=0.1, β=0)` 下，support proxy 选择 `scale=0.5`，但其独立 query harm 与初始
`scale=1` 完全相同，改善量为 `0 < 1e-4`。因此项目保持在 E4 Defender learning 之前，不修改阈值。

## 2. 冻结语义与信息边界

- Defender commitment 使用 versioned canonical JSON、`float.hex()` 与 SHA-256 fingerprint；每次
  support factory 调用前后验证，leader 不可变。
- Follower 是正、finite 的 `IPMScalePolicy`；solver clone caller initialization，只恢复 task-local snapshot。
- Support 只读取 same-round benign updates、follower malicious updates 与
  `state_after.global_model - state_before.global_model`；不读取 held-out evaluator、query seed、private
  diagnostics 或 E2 oracle matrix。
- Query 固定 selected snapshot，clean/attack 使用相同 seed、采样与初始模型，Episode 完成后才计算
  held-out loss；query 不调用 solver、不更新双方 policy。

## 5. Independent Query 与 Fixed Oracle

| commitment | initial scale-1 harm | adapted harm | improvement | Gate |
|---|---:|---:|---:|:---:|
| weak | 0.474697 | 77.581602 | 77.106905 | PASS |
| strong-clip | 0.529153 | 0.529153 | 0.000000 | **FAIL** |
| trim | 0.340103 | 70.312416 | 69.972313 | PASS |

同一个 frozen query 路径上的 fixed oracle harm：

| commitment | scale 0.5 | scale 1 | scale 3 | scale 8 |
|---|---:|---:|---:|---:|
| weak | 0.108045 | 0.474697 | 22.002558 | 77.581602 |
| strong-clip | 0.529153 | 0.529153 | 0.529153 | 0.529153 |
| trim | 0.089197 | 0.340103 | 15.164002 | 70.312416 |

strong clipping 把所有声明 IPM scales 压入几乎相同的 deployed transition，因此失败是 action/fixture
可辨识性结果，不是 solver tie-break 或 replay 偶然性。

## 6. Gate

| 要求 | 结果 |
|---|:---:|
| leader commitment fingerprint/freeze | PASS |
| caller follower initialization 不变 | PASS |
| support 无 oracle evaluator | PASS |
| 全 candidate × support seed fresh execution | PASS |
| support/query seeds disjoint | PASS |
| leader-dependent response curve | PASS |
| adapted query harm 对每个 commitment 改善 | **FAIL** |
| frozen query exact replay | PASS |
| fixed oracle 共用 query execution | PASS |
| dependency boundaries / canonical suite | PASS |

总结果：`passed=False`，`failed_requirements=('adapted query harm did not improve for strong-clip',)`。

## 7. 下一步

不能进入 E4。下一份获批设计应重审 strong-clipping 下 follower action 的可辨识性：可调整 commitment
集合、攻击可执行参数或 capability-safe proxy，但必须重新预声明并保持 query 隔离；不能用 query score
反向挑 candidate 或降低 Gate 阈值。
