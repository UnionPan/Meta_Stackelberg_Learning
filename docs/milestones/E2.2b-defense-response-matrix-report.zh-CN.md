# E2.2b Defense Response Matrix 与总 E2 Gate 报告

## 1. 阶段假设

E2.1 已验证单维 norm clipping 的可控性，E2.2a 已验证二维 action codec、等权 coordinate
trimmed mean 与固定 clip→trim 执行语义。E2.2b 固定所有 E1 attack/threat model/evaluator，回答：

1. α 与 β 是否在多个 attack tasks 上实际改变 aggregation 与独立 held-out 指标；
2. action grid 是否具有足够 active cells；
3. 不同 tasks 的多目标 nondominated action regions 是否不同；
4. 是否可以冻结 E2 物理动作并进入 E3 follower Best Response。

本阶段只运行 fixed attacks，不训练 attacker/defender，不把 response matrix 当作 learned policy 结果。

## 2. 模块和接口

- `DefenseGridPoint(clip_radius, trim_ratio)`：排序、验证过的二维物理坐标；
- `RawDefenseObservation`：task/seed/action/branch、final model、RNG、逐轮 aggregation/defense 统计、
  clean metric、task attack metric 与 immutable auxiliary components；
- `DefenseResponsePoint`：post-Episode matched harm、clip cost、trim cost；
- `DefenseResponseMatrix`：一个 task 的完整 seed × α × β × branch 结果和独立 E1 references；
- `MatrixGateThresholds` / `TaskMatrixGateResult`：返回实际 span、active ratio 和维度活跃状态；
- `E2GateResult`：required tasks、独立活跃维度、per-task nondominated regions、不同区域 task pairs 与
  明确 failed requirements。

execution packages 不导入 experiment orchestration。clean/attack engines 不含 defense branch，仍只接收
现有 `Aggregator` protocol。

## 3. 数据流与信息边界

```text
task × seed × α × β × branch
 -> fresh dataset views / model / trainers / sampler / attack generator
 -> ClippedTrimmedMean(α, β)
 -> fresh engine + EpisodeRunner
 -> final model
 -> post-Episode clean evaluator + task attack evaluator
 -> RawDefenseObservation
 -> matched validation (sampling / RNG / horizon / model structure)
 -> task-local harm and matrix gate
 -> within-task nondominated region
 -> cross-task E2 gate
```

ASR、held-out loss 和 auxiliary trigger metrics 不进入 Episode、attack generator、client trainer、
aggregation、RNG 或下一 action。不同 task 的 raw loss/ASR 不相加、不平均；跨任务只比较各自
多目标 nondominated action cell sets。

`active-cell ratio=1` 表示每个 cell 至少通过一个相邻 α 或 β edge 发生超过 `1e-5` 的变化，
不表示每条 edge 都活跃。因为 sample size 固定为 4：

```text
floor(4 × 0.0) = 0
floor(4 × 0.2) = 0
floor(4 × 0.4) = 1
```

所以 β=0 与 β=0.2 在全部 cell exact 相同；β 维证据来自相邻的 0.2→0.4 edge。这个离散台阶是
如实记录的 action-resolution 限制，不解释为 β=0.2 有效。

## 10. 已知限制

- 每 task 三 seeds，只是阶段 gate，不提供置信区间；
- grid 只有 3×3，不能推断连续 surface 的所有局部结构；
- sample size 4 使 β=0 与 0.2 完全等价，E3 action range/observation 必须显式包含 retained-count signal；
- strong clipping 会阻止 benign learning，不能只按 attack harm 选择动作；
- BFL 在当前 grid 仍有高 ASR，DBA 对 β=0.4 更敏感，不能宣称一个 defense 普遍有效；
- 当前 attacker 固定，不是 committed defender 下的 adaptive follower Best Response；
- nondominated region 不是 reward-weighted policy optimum。

## 12. 下一阶段前置条件

E2 通过后冻结以下语义进入 E3：

- physical action：`DefenseAction(α,β)`；
- codec：二维 `[-1,1]^2`；
- execution：per-client global-L2 clip→equal-client coordinate trim；
- observation candidates：update norm/coordinate statistics、clipped fraction、trim count、retained count、
  aggregate norm、历史 actions；
- evaluator protocols：loss harm 与 source-only ASR 分开；
- reference fingerprints 和 task-local response matrices；
- oracle 只 post-Episode。

E3 将固定 committed defender policy，训练 follower response，并验证 independent evaluation objective、
行为变化和随 leader policy 改变的 response curve。E3 不能在 environment 内重写 defense operator。
