# E1.2 BFL 定向后门攻击里程碑报告

## 1. 本阶段目标

E1.2 实现可单独验证的 BFL（Backdoor Federated Learning）路径：恶意客户端在本地数据上执行真实 trigger 注入与 source→target 标签替换，再通过正常本地 SGD 产生更新。攻击效果只由训练流程之外的独立 held-out oracle 评估。

本阶段不包含 DBA、IPM、LMP、隐蔽性优化、adaptive best response 或防御绕过；这些不能从本实验结果中推断。

## 2. 模块与边界

- `security/data/trigger.py`：不可变 patch trigger，返回输入副本，不修改原样本。
- `security/data/poisoning.py`：确定性 source-only poisoned dataset view。
- `security/attacks/backdoor.py`：trainer-backed BFL update generator。
- `evaluation/targeted.py`：训练路径之外的 held-out source-only ASR oracle。
- `integration/test_backdoor_attack_validity.py`：三 seed 匹配因果实验。

`security` 不导入顶层 `evaluation`。攻击执行阶段不能读取 held-out ASR，oracle 只在 Episode 完成后读取 final model。

## 3. 数据流

```text
malicious client's clean local subset
        ↓ SourceTargetPoisonedDataset
仅选择真实标签为 source 的固定索引
        ↓
PatchTrigger(image clone) + target relabel
        ↓
TorchLocalTrainer（真实 SGD）
        ↓
BackdoorLocalUpdateGenerator（校验 dataset 配置并标记 malicious）
        ↓
FedAvg → ServerSGD → final model

independent held-out clean dataset
        ↓ 只筛选真实 source-class 样本
apply trigger（不改标签、不改原数据）
        ↓
预测为 target 的数量 / held-out source 样本数 = ASR
```

poison selection 数量定义为：

```text
floor(poison_fraction × eligible_source_count)
```

选择由显式 `RandomSource` 驱动；fraction=0 不修改任何样本，fraction=1 投毒全部 source-class 样本。

## 4. 关键正确性约束

1. trigger 只覆盖声明区域，其他像素逐元素不变，底层 dataset 不被修改。
2. source/target 必须是非布尔、非负整数且彼此不同。
3. BFL generator 校验每个恶意客户端实际绑定 `SourceTargetPoisonedDataset`，并核对 source、target、fraction，避免仅写攻击元数据却使用 clean trainer。
4. ASR 分母只包含 held-out 数据中真实标签为 source 的样本；投毒训练标签不进入分母。
5. clean、identity、fraction=0 使用相同初始模型、采样 RNG、训练 RNG 与 FL 配置，并要求逐轮聚合/模型完全一致。
6. clean utility 与 ASR 同时报告，不能用 ASR 单指标宣称攻击有效且无代价。

## 5. 实验配置

```text
train examples:       120
held-out examples:    120（独立 TensorDataset，level offset 不同）
image shape:          1×8×8
classes:              source=0, target=1
trigger:              bottom-right 2×2, value=5.0
clients:              6
malicious clients:    {0,1,2}
sample size:           4 / round
horizon:               8 FL rounds
local SGD lr:          0.08
local epochs:          2
batch size:            8
aggregator:            sample-weighted FedAvg
server optimizer:      ServerSGD
seeds:                 401, 402, 403
```

## 6. 预期结果与判据

- clean = identity = BFL fraction=0：final clean metrics、final ASR、逐轮 sampled clients、aggregate delta、global model、parent RNG snapshot 完全相同。
- BFL fraction=1 相对 matched identity 的 held-out ASR 至少提高 0.8。
- fraction=1 的 held-out clean accuracy 不低于 0.95，并与 ASR 一起报告。
- 每轮至少采样 1 个恶意客户端；实际数量需要记录。

## 7. 实际结果

| Seed | Identity clean loss | Identity clean acc. | Identity ASR | BFL-1 clean loss | BFL-1 clean acc. | BFL-1 ASR | ASR gain |
|---:|---:|---:|---:|---:|---:|---:|---:|
| 401 | 0.0021274354 | 1.0 | 0.0 | 0.0043717593 | 1.0 | 1.0 | 1.0 |
| 402 | 0.0022040342 | 1.0 | 0.0 | 0.0041447845 | 1.0 | 1.0 | 1.0 |
| 403 | 0.0021523050 | 1.0 | 0.0 | 0.0048156453 | 1.0 | 1.0 | 1.0 |

clean、identity、BFL fraction=0 在三个 seed 上通过全部 exact-equivalence 断言。

每轮采样的恶意客户端数：

```text
seed 401: 2,1,3,2,2,2,2,2
seed 402: 2,3,2,2,1,2,1,1
seed 403: 2,2,2,1,2,2,3,2
```

三组 matched 实验均得到 ASR gain=1.0，clean accuracy=1.0；clean loss 有小幅上升，因此结论只限定为“该受控合成任务上，真实 poisoned local training 建立了稳定后门行为”，不推广到真实数据集或任意模型。

## 8. 测试与审查证据

覆盖内容包括：

- 2-D/3-D trigger、边界、dtype 可表示性和无 mutation；
- source-only deterministic selection、fraction 0/1、非法 class/fraction；
- BFL generator scope、dataset/config 一致性、metadata；
- ASR 手工可计算分母、batch-size independence、Python int/tensor label、空分母和无 mutation；
- 三 seed matched Episode 与 clean utility/ASR 联合门槛；
- `security → evaluation` 依赖禁令。

独立只读审查发现的忽略规则、训练语义绑定、Python int 标签和类别 ID 校验问题均在最终 gate 前修复。

## 9. 局限与下一步

- 当前 fixture 是线性可分的合成 1×8×8 数据，只用于验证模块语义和因果证据链。
- 当前 BFL 是 fixed source-target patch backdoor，不包含 trigger stealth、semantic backdoor 或自适应攻击。
- ASR 必须继续与 clean loss/accuracy 联合报告。
- 下一阶段 E1.3 迁移 IPM/LMP；E1.4 在本阶段 trigger、poison dataset 与 ASR oracle 上增加 DBA 的 per-attacker sub-trigger 分工。

## 10. E1.2 Gate

E1.2 的通过条件为：trigger 与数据无 mutation、确定性 source-only poison、fraction=0 exact identity、held-out ASR 分母正确、matched RNG/采样、三 seed strong-poison ASR 提升、clean utility 联合报告、依赖边界通过。最终是否通过以提交前 fresh full-suite 输出为准。
