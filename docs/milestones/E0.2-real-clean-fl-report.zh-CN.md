# E0.2 真实 Local SGD 与 Clean FL 收敛验证报告

## 1. 阶段假设

E0.2 验证以下假设：

> E0.1 的可插拔 RoundEngine 可以在不修改 orchestration 的情况下接入真实 PyTorch local training、确定性数据划分、随机客户端采样和独立 evaluator，并在一个无需下载的数据集上产生方向正确、可精确重放的 clean-FL 学习过程。

本阶段所称“真实”指真实 PyTorch forward、cross entropy、backward 和 SGD，不表示已经完成 MNIST/CIFAR 或大规模 FL 复现。

## 2. 新增模块

### 2.1 IID Partition

文件：`meta_stackelberg/federated/data/partitioning.py`

接口：

```python
iid_partition(num_samples, num_clients, rng)
```

性质：

- 每个样本恰好属于一个客户端；
- 客户端之间没有重叠；
- 最大和最小分区大小相差不超过 1；
- 相同 seed 返回相同结果；
- 不使用 NumPy 全局 RNG。

### 2.2 UniformClientSampler

文件：`meta_stackelberg/federated/clients/sampling.py`

使用显式 `RandomSource.numpy` 无放回采样客户端。它满足 E0.1 定义的 `ClientSampler` protocol，因此 `RoundEngine` 不需要知道具体采样算法。

### 2.3 TorchParameterCodec

文件：`meta_stackelberg/federated/models/parameters.py`

负责：

```text
PyTorch trainable parameters <-> ModelState
```

当前只处理 `model.parameters()`，显式不处理 BatchNorm buffer 等 `state_dict` buffer。加载前检查参数数量和 shape，并复制只读 NumPy tensor，避免 PyTorch 非可写数组警告和未定义行为。

### 2.4 TorchLocalTrainer

文件：`meta_stackelberg/federated/clients/trainer.py`

每次调用都：

1. 创建新 model；
2. 从 global `ModelState` 加载参数；
3. 创建新 SGD optimizer；
4. 使用 client dataset 和显式 Torch generator 创建 DataLoader；
5. 执行 local epochs；
6. 返回 `local_model - global_model`；
7. 记录样本平均 train loss 和 train accuracy。

trainer 不复用其他客户端的 optimizer state，也不修改传入的 global state。

### 2.5 ClassificationEvaluator

文件：`meta_stackelberg/federated/evaluation/classification.py`

独立于 `RoundEngine`，返回：

```python
ClassificationMetrics(
    loss,
    accuracy,
    num_examples,
)
```

loss 按样本加权平均，与 batch size 无关。空 dataset 返回有限的零指标和 `num_examples=0`。

## 3. 数据流

```text
in-memory TensorDataset
        ↓
iid_partition(seed=101)
        ↓
4 × client Subset
        ↓
RoundRequest(state_t, sample_size=4)
        ↓
UniformClientSampler
        ↓
4 × TorchLocalTrainer
        ↓
4 × ClientUpdate
  delta = local - global
  num_examples = client dataset size
        ↓
FedAvg weighted by num_examples
        ↓
ServerSGD(server_lr=1.0)
        ↓
RoundState_{t+1}
        ↓
ClassificationEvaluator
        ↓
loss/accuracy history
```

evaluation 不进入 RoundEngine，也不影响下一轮状态。

## 4. 测试数据与模型

数据集由 80 个二维样本组成：

```text
class 0: 40 个位于负象限的点
class 1: 40 个位于正象限的点
```

模型：

```text
Linear(2, 2)
```

初始 weight 和 bias 全部为 0，因此初始 logits 相同：

```text
initial cross entropy ≈ log(2)
initial accuracy = 0.5
```

FL 配置：

```text
clients = 4
clients selected per round = 4
local epochs = 2
local batch size = 8
local learning rate = 0.2
server learning rate = 1.0
rounds = 10
```

## 5. 预期结果

阶段 gate 不硬编码特定最终参数，但要求：

- final loss 小于 initial loss；
- final accuracy 至少为 0.95；
- 每轮包含四个 benign updates；
- 不产生 malicious updates；
- 相同初始 seed 和 snapshot 重跑得到完全相同的参数和 metric history。

## 7. 确定性重放

完整十轮实验从头执行两次。两次运行分别重建：

- dataset；
- IID partition；
- model；
- RandomSource；
- client sampler；
- local trainer；
- RoundEngine；
- evaluator。

验证结果：

```text
final parameter vector: exact equality
10-round metric history: exact equality
```

这证明当前 CPU、单 worker、无 dropout、无 model buffer 配置下，canonical clean-FL 流程能够由 seed 和 RoundState snapshot 重放。

## 10. 可插拔性结论

E0.2 没有修改 E0.1 的 `RoundEngine`。以下 scripted plugins 被真实实现替换：

```text
Fixed/Random test sampler -> UniformClientSampler
ScriptedTrainer           -> TorchLocalTrainer
manual model arrays       -> TorchParameterCodec
test-only metric          -> ClassificationEvaluator
```

FedAvg、ServerSGD、RoundRequest、RoundState 和 RoundTransition 均原样复用。这是本阶段最主要的模块可插拔证据。

## 11. 已知限制

本阶段仍未覆盖：

- PyTorch model buffers；
- BatchNorm、Dropout；
- CUDA determinism；
- DataLoader 多 worker；
- partial client participation convergence；
- non-IID partition；
- CNN 和真实图像数据；
- momentum/Adam client optimizer；
- server optimizer state；
- attacks 和 defenses。

这些限制不能用当前线性数据结果外推。

## 12. E0.2 Gate 结论

E0.2 通过，因为：

- 每个新增模块有独立单元测试；
- 真实 local SGD 使用 canonical delta；
- evaluator 与 transition 分离；
- 线性可分 clean FL 方向正确并达到预期阈值；
- 全流程精确重放；
- RoundEngine 无需修改即可接入真实 plugins；
- canonical、legacy 和 dependency tests 全部通过。

## 13. E0.3 建议范围

下一阶段继续扩展 clean FL，而不是进入攻击：

1. model registry 和带 buffer 的完整 state codec；
2. deterministic non-IID partition；
3. partial client participation；
4. MNIST-compatible CNN；
5. synthetic image convergence test；
6. 可选的本地 MNIST smoke protocol；
7. multi-round checkpoint/snapshot，包括 model buffer 和 sampler 状态。

只有 E0 clean-FL gate 完整通过后才进入 E1 attack validity。
