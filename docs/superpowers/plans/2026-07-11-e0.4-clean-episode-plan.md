# E0.4 Clean Episode and RNG Isolation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将多轮 clean FL 提升为正式、可插拔、可精确续跑的 Episode，并隔离 sampling 与每个 client 的随机数消费，为 E1 matched attack comparison 建立无混杂基线。

**Architecture:** `RandomSource.spawn()` 从 parent NumPy stream 派生独立 child source；`RoundEngine` 每轮只让 parent 派生一个 sampling child 和每个 sampled slot 一个 client child。`EpisodeRunner` 只依赖 `RoundExecutor` protocol，连续构造 `RoundRequest` 并返回 immutable `FederatedTrajectory`，不计算 reward 或 evaluation。

**Tech Stack:** Python 3.12、NumPy、PyTorch、pytest、dataclasses、typing.Protocol。

**Status:** 2026-07-11 已完成；实现与验证证据见 `docs/milestones/E0.4-clean-episode-report.zh-CN.md`。

Implement:

```python
@dataclass(frozen=True)
class EpisodeSpec:
    task_id: str
    horizon: int
    sample_size: int
    server_lr: float
    initial_state: RoundState

@dataclass(frozen=True)
class FederatedTrajectory:
    task_id: str
    initial_state: RoundState
    transitions: tuple[RoundTransition, ...]
    final_state: RoundState

class EpisodeRunner:
    def __init__(self, executor: RoundExecutor) -> None:
        self.executor = executor

    def run(self, spec: EpisodeSpec, rng: RandomSource) -> FederatedTrajectory:
        state = spec.initial_state
        transitions = []
        for _ in range(spec.horizon):
            transition = self.executor.run_round(
                RoundRequest(
                    task_id=spec.task_id,
                    state=state,
                    sample_size=spec.sample_size,
                    server_lr=spec.server_lr,
                ),
                rng,
            )
            _validate_transition(spec.task_id, state, transition)
            transitions.append(transition)
            state = transition.state_after
        return FederatedTrajectory(
            task_id=spec.task_id,
            initial_state=spec.initial_state,
            transitions=tuple(transitions),
            final_state=state,
        )
```

The runner constructs one `RoundRequest` per step, verifies task identity and state continuity, and never evaluates metrics or mutates an agent.
