# E0.3 Realistic Clean FL Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在不引入攻击与防御变量的前提下，证明 canonical FL 核心能够确定性处理 label-skew non-IID、部分参与、小型 CNN，以及带随机状态的中断续跑。

**Architecture:** 数据划分、模型构造、round 编排和持久化保持为四个独立模块。Checkpoint 只序列化 `RoundState` 的训练参数、显式随机源和 JSON-compatible component state；PyTorch buffer 不会被当前 parameter codec 静默纳入，含 buffer 模型必须在后续独立定义同步语义。

**Tech Stack:** Python 3.12、NumPy、PyTorch、pytest、标准库 JSON/ZIP。

**Status:** 2026-07-11 已完成；实现结果与验证证据见 `docs/milestones/E0.3-realistic-clean-fl-report.zh-CN.md`。

---

## File map

- `meta_stackelberg/federated/data/partitioning.py`: 增加 Dirichlet label-skew 划分。
- `meta_stackelberg/federated/models/registry.py`: 模型名到无参 factory 的显式注册表。
- `meta_stackelberg/federated/models/tiny_cnn.py`: 无 BatchNorm、无持久 buffer 的 1×8×8 clean-FL smoke model。
- `meta_stackelberg/federated/checkpointing/round_state.py`: 版本化、pickle-free 的 ZIP/JSON/NPY `RoundState` checkpoint。
- `tests/meta_stackelberg/unit/test_non_iid_partitioning.py`: non-IID 合约测试。
- `tests/meta_stackelberg/unit/test_model_registry.py`: 注册与模型结构测试。
- `tests/meta_stackelberg/unit/test_round_checkpoint.py`: checkpoint round-trip、错误输入与 RNG 恢复测试。
- `tests/meta_stackelberg/integration/test_realistic_clean_fl.py`: non-IID + partial participation + CNN + exact resume 纵向验证。
- `docs/milestones/E0.3-realistic-clean-fl-report.zh-CN.md`: 中文证据报告。

## Acceptance boundary

E0.3 通过仅说明：clean FL 在受控 non-IID、partial participation、buffer-free CNN 环境中可学习且可精确续跑。它不说明攻击有效、防御有效、Stackelberg best response 成立或 meta-generalization 成立；这些分别属于 E1–E6。
