# E1.1 Fixed Untargeted Attack Validity Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在不泄漏 benign updates 或 oracle 信息的前提下，实现可插拔 malicious population、identity/no-op 和 delta-reversal attack，并用 matched Episodes 证明强 untargeted attack 对 clean utility 产生方向正确的 harm。

**Architecture:** `security` 层只接收最小 `AttackContext`，内建 malicious generator 只包装限定恶意客户端 IDs 的 `ScopedLocalTrainer`。所有 client training 使用无 server component state 的统一 client view；clean 与 attack engines 共用 federated 层的中立 round preparation/finalization kernel，保证相同 initial snapshot 下派生相同 sampling/per-slot RNG，且聚合始终按 sampled order执行。

**Tech Stack:** Python 3.12、NumPy、PyTorch、pytest、typing.Protocol、dataclasses。

**Status:** 2026-07-11 已完成；实现与验证证据见 `docs/milestones/E1.1-fixed-untargeted-attack-report.zh-CN.md`。

### Task 1: Capabilities, knowledge and population

- [ ] Write failing tests for six capability flags, exact allowed/rejected validation, immutable unique non-negative fixed IDs, and structural protocols.
- [ ] Verify RED because `meta_stackelberg.security` does not exist.
- [ ] Implement frozen `AttackCapabilities`, `AttackKnowledge`, `AttackContext`, `validate_capabilities`, `FixedMaliciousPopulation`, `MaliciousPopulation` and `MaliciousUpdateGenerator`.
- [ ] Verify every mismatch fails before any trainer can be called.

The allowed relation is exact:

```text
capability=True and corresponding knowledge=False → ValueError
all required capabilities allowed → pass
```

### Task 2: Identity malicious generator

- [ ] Write a failing hand fixture using a recording `LocalTrainer`.
- [ ] Require the generator to use a `ScopedLocalTrainer` and the same sanitized client state contract as clean/benign training: only round index, global model, child RNG snapshot and empty component states.
- [ ] Require returned delta, sample count and training metadata to equal the base update, while `client_id` matches context and `is_malicious=True`.
- [ ] Implement `IdentityMaliciousUpdateGenerator` and verify it satisfies the runtime protocol.

### Task 3: Delta reversal operator

- [ ] Write failing numerical fixtures for base delta `[1, -2]` and budgets 0, 1 and 2.
- [ ] Require outputs `[1,-2]`, `[0,0]`, `[-1,2]` respectively.
- [ ] Verify exact displacement ratio `||crafted-base|| / ||base|| = budget` for nonzero base.
- [ ] Require zero base to remain zero with ratio zero; reject negative/non-finite budget and wrong base client ID.
- [ ] Implement `DeltaReversalAttack` by wrapping an injected `ScopedLocalTrainer`; do not observe task id、其他客户端或 oracle data.

### Task 4: Shared round kernel

- [ ] Write/extend behavioral tests proving current clean RoundEngine output, replay and plug-in behavior remain unchanged at the contract level.

- [ ] Extract `finalize_round(request, parent_rng, ordered_updates, aggregator, server_optimizer, private_diagnostics)`.

### Task 5: AttackRoundEngine

### Task 6: Matched Episode validity experiment

- [ ] Build an in-memory linearly separable train dataset and an independent held-out dataset.

- [ ] Require clean and identity sample histories, parent RNG snapshots, aggregate/model trajectories and held-out metrics to be exactly equal.

- [ ] Report per-seed final loss harm, accuracy harm, sampled malicious counts and operator budgets.

## E1.1 gate

E1.1 passes only when all of the following are true:

```text
capability compliance
+ identity exact model/RNG equivalence
+ delta reversal hand mathematics
+ sampled-order aggregation
+ matched sample/RNG trajectories
+ positive held-out untargeted harm across the declared seed set
+ oracle evaluation remains outside security and Episode
```

Backdoor ASR、defense action、RL reward、Best Response 和 Meta update 不属于本计划。
