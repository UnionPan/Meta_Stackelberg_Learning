# E2.2b Defense Response Matrix Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build deterministic two-dimensional defense response matrices for every E1 attack family and use precommitted task-local thresholds to decide the total E2 controllability gate.

**Architecture:** Generalize E2.1's matched raw-observation pattern to immutable `(clip_radius, trim_ratio)` coordinates and task-local metric components. Keep experiment orchestration above execution packages. Each E1 fixture owns its evaluator adapter, while a shared runner enforces grid coverage, fresh construction, clean/attack matching, independent no-op references, replay and active-cell calculations.

**Tech Stack:** Python 3.12, NumPy, PyTorch, dataclasses, pytest.

@dataclass(frozen=True, order=True)
