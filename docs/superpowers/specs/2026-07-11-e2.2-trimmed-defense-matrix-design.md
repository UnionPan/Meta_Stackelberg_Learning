# E2.2 Trimmed Defense Matrix Design

## 1. 文档状态与阶段边界

本文档定义 E2 的第二个交付阶段：在 E2.1 已验证的 `clip_radius α` 基础上增加
`trim_ratio β`，形成论文语义的 norm bounding + coordinate-wise trimmed mean 二维防御动作，
并分别在 fixed untargeted、BFL、IPM/LMP 与 DBA 上建立 matched response matrix。

E2.2 仍不训练 policy、不实现 follower Best Response、不更新双方 agent，也不执行 meta update。
本阶段的职责是冻结可执行、可解释、可网格扫描的 defense action surface，为 E3–E5 的后三个
时间尺度提供可信物理动作。

## 2. 四时间尺度衔接

```text
FL Round
  DefenderAction(α, β)
  -> clip each client update
  -> coordinate-wise trim
  -> aggregate delta

Episode
  fixed or scripted action sequence
  -> H canonical rounds
  -> trajectory without learner updates

Best Response / Adaptation
  policy output
  -> shared 2D codec
  -> exact same physical aggregation path

Meta Iteration
  per-task support/query runs
  -> task-local action sequence and response record
  -> no second defense implementation
```

## 3. 算法语义

### 3.1 DefenseAction

扩展现有不可变动作：

```python
@dataclass(frozen=True)
class DefenseAction:
    clip_radius: float
    trim_ratio: float = 0.0
```

- `clip_radius` 必须有限且严格为正；
- `trim_ratio` 必须有限并位于 `[0, 0.5)`；
- `trim_ratio=0` 是合法消融点；
- bool 不作为数值接受。

默认 `trim_ratio=0` 保持 E2.1 API 和既有测试兼容。

### 3.2 等权 coordinate-wise trimmed mean

对 `n` 个结构和 dtype 一致的 client deltas，令：

```text
k = floor(n * β)
```

对每个 tensor coordinate 独立排序，删除最小 `k` 和最大 `k` 个值，对剩余
`n - 2k` 个值做等权算术平均。`ClientUpdate.num_examples` 不参与排序或均值。

选择等权语义是为了对应 robust aggregation 文献和现有 Meta-SG paper defense。若将样本权重
引入排序后的均值，会形成不同算法，必须另立阶段验证。

约束：

- `0 <= β < 0.5`；
- `n - 2 floor(nβ) >= 1`；
- `k=0` 时与等权 coordinate mean exact，不默认与 sample-weighted FedAvg 等价；
- client 输入顺序不影响结果；
- 输入 update、ModelState 和 ndarray 不修改；
- 不读取 client ID、malicious flag、metadata 或 oracle。

### 3.3 组合顺序

组合 defense 固定为：

```text
raw client deltas
 -> per-client global L2 clipping with α
 -> coordinate-wise trimmed mean with β
 -> aggregate delta
```

不能先 trim 后 clip aggregate；二者不等价。组合器复用 E2.1 的单 update clipping primitive，
避免产生第二套 norm 和 dtype 语义。

## 4. 模块与接口

### 4.1 二维 codec

保留 `ClipRadiusActionCodec`，新增：

```python
ClippedTrimmedActionCodec(
    min_clip_radius,
    max_clip_radius,
    max_trim_ratio=0.4,
)

decode(np.ndarray(shape=(2,))) -> DefenseAction
encode(DefenseAction) -> np.ndarray(shape=(2,))
```

映射：

```text
a[0] ∈ [-1, 1] -> α ∈ [min_clip_radius, max_clip_radius]
a[1] ∈ [-1, 1] -> β ∈ [0, max_trim_ratio]
```

`max_trim_ratio` 必须有限且位于 `(0, 0.5)`。shape、floating dtype、finite 和 range 在调用
round 前 fail fast。encode/decode 在浮点容差内互逆。

### 4.2 CoordinateTrimmedMean

新增 `meta_stackelberg/security/defenses/trimmed_mean.py`：

```python
CoordinateTrimmedMean(trim_ratio: float)
aggregate(updates: Sequence[ClientUpdate]) -> ModelState
summarize(client_count: int) -> TrimmingSummary
```

`TrimmingSummary` 记录 client count、trim ratio、per-tail trim count、retained count。
aggregator 必须满足现有 `Aggregator` protocol。

### 4.3 ClippedTrimmedMean

新增组合器：

```python
ClippedTrimmedMean(clip_radius: float, trim_ratio: float)
aggregate(updates) -> ModelState
summarize(updates) -> DefenseAggregationSummary
```

它复用 E2.1 clipping helper 生成临时 updates，再委托 `CoordinateTrimmedMean`。summary 是纯函数，
不依赖上一次 aggregate 的 mutable cache。

## 5. Response Matrix

新增通用二维坐标：

```python
DefenseGridPoint(clip_radius, trim_ratio)
```

runner 扫描：

```text
task
 × seed
 × clip_radius
 × trim_ratio
 × clean/attack branch
 -> independent raw observations
 -> matched validation
 -> task-specific harm
 -> response matrix
```

每次 factory 调用必须重建 snapshot、dataset view、trainer、sampler、attack generator、aggregator、
engine、EpisodeRunner 和 parent RNG。不得从前一个 grid point 恢复或继续推进。

记录：

- task/evaluation protocol fingerprint；
- seed、α、β、branch；
- sampled clients 和 final parent RNG；
- per-round aggregate norms；
- clipped fractions、trim count、retained count；
- final model vector；
- clean loss/accuracy；
- attack-specific metric 与 matched harm；
- defense/action cost。

## 6. 攻击矩阵与 evaluator

四类攻击继续使用已通过 E1 gate 的 threat model、matched fixture 和 evaluator：

| task | aggregation baseline | attack metric | clean metric |
|---|---|---|---|
| Delta Reversal | FedAvg | held-out loss harm | loss/accuracy |
| BFL | FedAvg | held-out source-only ASR | loss/accuracy |
| IPM | FedAvg | held-out loss/accuracy harm | loss/accuracy |
| LMP | CoordinateMedian 原证据 + trimmed family 新实验 | held-out loss/margin harm | loss/accuracy |
| DBA | FedAvg | held-out source-only full-trigger ASR | loss/accuracy |

IPM 与 LMP 分别记录，不能用 “IPM/LMP” 单点代替两个攻击结果。DBA 同时保留 sub-trigger 与
full-trigger 指标，但 E2 task harm 只使用 E1.4 定义的 source-only full-trigger ASR。

不同 task metric 不压成未经定义的统一 scalar。跨任务只比较 action region、非平坦性、clean
trade-off 和 normalized within-task rank；原始指标完整保留。

## 7. Grid 与成本

E2.2 先使用离散二维 grid，不训练连续 policy：

- clip radii 复用或按每个 fixture 的 no-clip reference 标定；
- trim ratios 至少包含 `0.0, 0.1, 0.2, 0.3, 0.4`；
- 每个 task 至少三个 declared seeds；
- `β=0` 必须与 `ClippedAggregator(EqualMean)` exact；
- 每个 task 另跑不经过二维 defense 的原 E1 baseline 作为 reference；只有 client sample counts
  全部相等时，才允许额外声明 grid 的 no-clip/zero-trim 点与 FedAvg exact。

成本分别记录，不预先压成一个 reward：

```text
clip_cost = log(reference_radius / α)
trim_cost = β / max_trim_ratio
```

E4 reward 设计前再决定组合权重。

## 8. 可控性与 E2 Gate

每个 task 在运行结果前固定：

- aggregate non-flat threshold；
- task metric non-flat threshold；
- reference equivalence tolerance；
- active-cell ratio threshold。

E2 gate 同时要求：

1. 2D codec 非法输入 fail fast，合法输入 round-trip；
2. trimmed mean 手算、permutation、dtype、structure 和 input immutability 成立；
3. `β=0` 与等权 mean exact；
4. composition 顺序通过反例证明为 clip-then-trim；
5. 独立 reference branch 与每个 E1 baseline 的 sampling、RNG、aggregate、model 和 metrics exact；
6. 每个 task response matrix deterministic replay；
7. 四个攻击 family、IPM 与 LMP 分项均有完整结果；
8. 至少两个 task 的较优 action region 不同；
9. 每个动作维度至少在一个 task 上产生超过阈值的独立影响；
10. action grid active-cell ratio 达到预声明阈值，不存在大片无效区；
11. clean utility、attack harm、clip cost、trim cost 联合报告；
12. oracle isolation、依赖边界、canonical 和全仓测试通过。

若 trimmed mean 对某个攻击/fixture 平坦，必须如实报告；E2 总 gate 只在 action dimension 对研究
任务分布具有足够可辨识性时通过，不能删除平坦 task 或看到结果后改变阈值。

## 9. 错误处理

- 非法 α/β、grid duplicate、unsorted coordinate、空 seed、non-finite metric 立即失败；
- task/evaluation protocol 不匹配禁止比较；
- factory 返回错误坐标、不同 sampling/RNG、不同 model shape 或 horizon 时拒绝 point；
- 单 task 失败与其他 task state 隔离；
- partial matrix 不写成 PASS report；
- 独立 no-op/reference 未 exact 时不得继续解释 defense effect；不得把一般的 `β=0` 等权点冒充
  sample-weighted FedAvg reference。

## 10. 测试策略

### 单元

- `DefenseAction` 二维 validation；
- 2D codec endpoint、round-trip、shape/dtype/finite/range；
- odd/even client count 与多个 β 的 `floor(nβ)`；
- scalar、vector、多 tensor 手算；
- β=0、near-0.5、empty、NaN、structure/dtype mismatch；
- permutation、input immutability、equal-client weighting；
- clip-then-trim composition counterexample；
- pure summaries 与 protocol conformance。

### 集成

- clean/attack branch matching；
- grid point fresh construction；
- full matrix replay；
- per-task 独立 E1 reference exact；等样本数 fixture 另验 grid reference exact；
- post-Episode evaluator；
- complete task × seed × action coverage；
- precommitted controllability thresholds。

### 回归

- E2.1 one-dimensional action/response behavior不变；
- clean FL、四类攻击和 dependency boundaries 全部继续通过；
- `security/defenses` 仍不能导入 experiment/oracle 层。

## 11. 已知限制

- coordinate-wise trimmed mean 不保留 client update 的跨坐标联合结构；
- 小 sample size 使 β 呈离散台阶，连续 policy 的小变化可能映射到同一 `k`；
- 等权 aggregation 与 FedAvg 的 sample weighting 不同，必须作为明确 defense family 报告；
- 三 seeds 用于阶段 gate，不支持总体置信区间；
- fixed attacks 不是 adaptive follower Best Response；
- E2 通过只证明 action controllability，不证明 defender 可学习或 meta generalization。

## 12. 后续阶段

E2.2 完成并通过 E2 gate 后，冻结：

- physical action semantics；
- 2D codec range；
- task/evaluation fingerprints；
- candidate observation statistics；
- action cost components；
- response matrix baselines。

随后进入 E3：固定 committed defender policy，训练和验证 follower Best Response。E3 必须调用本阶段
同一 codec 与 aggregation path，不能在 RL environment 内重新实现 clipping 或 trimmed mean。
