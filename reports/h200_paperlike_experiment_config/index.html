1. 实验目标

这条主线不是单独训练一个固定防御规则，而是在多个攻击任务上做 Meta-Stackelberg / Reptile 风格预训练。 训练结束后得到一个共享的 defender 初始神经网络。理论上，它应该作为不同场景 adaptation 的起点， 在看到当前场景的在线反馈后快速微调到更合适的防御动作。

Step 1 采样任务

K=10 个任务来自 clean, bfl, dba, rl_backdoor, mixed_backdoor。

Step 2 复制初始网络

从共享 defender actor/critic 初始化出发，对每个任务做内层 TD3。

Step 3 任务内 adaptation

每个任务跑 H=200 FL rounds，并做 l=10 次 defender TD3 更新。

Step 4 Query 约束筛选

用 query reward / clean drop / ASR reduction 判断更新是否进入 meta update。

Step 5 Reptile meta update

把共享初始化朝多个任务 adaptation 后的参数平均方向移动。

报告里把这个共享初始化称为“初始策略网络”。它不是每个攻击类型一个完全独立的 defender 网络； 不同攻击类型下的差异，预期主要来自后续 adaptation 对这个共享初始化的微调。

3. 任务混合方式

clean_backdoor_mixed 不是普通 model poisoning 混合域。它由 clean、三个单一后门攻击、 以及一个同轮次内混合多种后门客户端的 mixed_backdoor 组成。 K=10 使用 stratified sampler，因此每个 outer iteration 通常先覆盖 5 类任务，再填充额外任务。

clean 无攻击 baseline，用于约束 clean accuracy。
bfl 单一 BFL 后门任务。
dba 单一 DBA 分布式后门任务。
rl_backdoor sandbox 内部原生 RL 后门逻辑。
mixed_backdoor 同一轮 malicious clients 分成 BFL / DBA / RL-backdoor 三组。
mixed_backdoor 角色 6 个攻击客户端时的划分 说明

RL-backdoor role attacker 4, 5 使用 RLBackdoorAttack 的原生内部逻辑。
评估修复后，attacker action 走统一 native 链路。defender 不应直接看到 attacker action； history feature 中保留的是固定维度占位，不再把攻击方 raw action 暴露给 defender。

4. Meta Learning 学到的网络

当前 checkpoint 中的核心产物是 defender_meta.pt。它包含一个 TD3 defender， 其中 actor 是确定性策略网络，critic 是 twin-Q 网络。actor 输入当前 FL 状态观测，输出三维 raw action； raw action 经 tanh 限制在 [-1, 1]^3，再映射成真实防御参数。

Actor: 初始策略网络

输入FL 状态观测 obs
结构Linear -> ReLU -> Linear -> ReLU -> Linear -> Tanh
hidden dim256, 256
输出raw action in [-1, 1]^3
训练目标最大化 defense score / reward

Critic: TD3 双 Q 网络

输入concat(obs, action)
结构Q1 和 Q2 两套 MLP
hidden dim256, 256
输出Q1(s,a), Q2(s,a)
用途给 actor 更新提供 TD3 价值估计
从 meta learning 角度看，训练不是直接记住某个攻击的固定 action，而是学习一个能在多种任务上作为 adaptation 起点的参数初始化。当前结果的问题是：这个初始化本身已经很强，后续 online TD3 adaptation 在弱信号下反而容易把策略推离当前较优点。

4. 阶段性结论

epsilon/neuroclip 三维看到的问题

它没有出现 server_lr 主线那种 clean 后期崩掉的现象，说明不直接控制 server learning rate 能避免“停训防御”。但强后门场景下 ASR 过高，尤其 BFL 与 RL-backdoor 接近 0.91-0.97， 说明仅靠 epsilon 后处理不足以覆盖这些攻击。

与 server_lr 三维互补

server_lr 三维能压 ASR，但容易牺牲 clean；epsilon 三维保 clean，但强攻击 ASR 压不住。 这就是为什么四维 alpha,beta,neuroclip_epsilon,server_lr 是合理下一步：把训练过程控制和后处理防御拆开，同时需要给 server_lr 加下限/惩罚。

4D both 诊断实验总览

这条实验把三维 server_lr 与三维 epsilon 的思路合并成四维动作： alpha, beta, neuroclip_epsilon, server_lr。 但当前报告里的 4D 曲线来自一条 H=100 diagnostic run，不是 H=200 paperlike 主线的严格四维复刻。 它可以帮助观察四维 action 的训练趋势，但不能和前两个主实验直接做结论级比较。
